## What this does not establish

- Every test mocks the provider's HTTP response (`httpx.MockTransport`) and uses synthetic credentials. No request left the machine. This proves the evidence path only. It does not show what a live provider returns.
- `redact_text` removes the patterns it knows and the configured credential values. `sanitized=true` means those rules ran. It cannot prove that a credential in an unknown format is absent.
- For a JSON-string body, the stored copy is the decoded, redacted text, so `original_format` is `text`. The exact original bytes are represented by `original_sha256` only, and they are deliberately not stored.
- Account support for `kroger_search` and the proposed route, and genuine Vernon Hills Pickup store-qualified data, are still unverified.
