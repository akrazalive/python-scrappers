   15  ## Data flow per run
   16  
   17  1. **Store verification** – a canary search page is read with the store pinned. The page's store details
   18     (`modalityPreferences.storeDetails`) must show the configured location id, ZIP and address; the search request
   19     itself must carry that location id; every price on the page must have `sourceLocationId` = configured store.
   20  2. **Canary (start)** – the canary search must return store-priced products including the configured canary UPCs.
   21  3. **Discovery** – each `/d/<department>` URL from the CSV is opened; its sub-category links
   22     (`navItems`) become listings. `/pl/<slug>/<taxonomy>` links are read through Mariano's search
   23     (the `/pl/` pages themselves are not served to automated clients) and filtered to products whose
   24     `subCommodityCode` starts with that taxonomy id, so a product is only assigned to the sub-category it belongs to.
   25     Curated shelves (e.g. *Steaks*) are read from their own search URL and filtered to the department code.
   26     Pure brand shelves (*Simple Truth*, *Private Selection*, *Kroger*) are skipped – they only repeat products of real
   27     sub-categories. `/pl/` rows in the CSV (Batteries, Light Bulbs, …) are one listing each.
   28  4. **Crawl** – every listing is paged (24 per page) until Mariano's returns a short page (end of results), three
   29     consecutive pages contain nothing of the target sub-category, or the ~1,000-result search window is reached
   30     (reported as a warning). Each page is committed atomically with its records.
   31  5. **Coupons** – the CSV's coupons URL is rendered and every displayed digital coupon (id, wording, expiry) is saved
   32     to `coupons.json`.
   33  6. **Canary (end)**, **validation**, **report**, **publication** (only if valid).
   34  
   35  ## Field rules
   36  
   37  | Field | Source / rule |
   38  |---|---|
   39  | zipcode, store_name, store_location | store details of the verified store (e.g. `60014`, `Marianos Crystal Lake`, `105 Northwest Hwy, Crystal Lake, IL 60014`) |
   40  | store_logo | Mariano's logo image on the page |
   41  | store_brand | `yes` when the brand is in `config/private_label_brands.txt` (Roundy's, Kroger, Simple Truth, Private Selection, …), else `no` |
   42  | category / sub_category | CSV category / Mariano's sub-category name from the department page |
   43  | product_title | item description |
   44  | weight | `customerFacingSize` as displayed (e.g. `1/2 gal`, `6 ct / 8 fl oz`) |
   45  | regular_price | store regular price |
   46  | sale_price | store promo price when it is a single-unit price lower than regular (what the card shows as Sale/Price Cut) |
   47  | volume_deals_* (v1.1.0: + terms) | multi-buy prices (`nfor` > 1, e.g. "2 for $5.00" → price 5.00) and offers that need no clipping (e.g. `MEGA_EVENT` "Save $1 each when you buy 5 or more" → description only, no calculated price) |
   48  | digital_deals_* | offers requiring clip / digital coupon; price only when written ("$3.99 each with Digital Coupon") |
   49  | image_url | the product-card image URL (front, medium) exactly as served |
   50  | url | Mariano's product URL (`shareLink`) |
   51  | upc | Mariano's 13-digit UPC, never modified |
   52  | gupc, unit_price | always `""` |
   53  | ppm | `equivalizedUnitPriceString` exactly as displayed, from the price the card shows (promo if on sale) |
   54  | crawl_date | run date (YYYY-MM-DD), last field |
   55  
   56  Retention (v1.1.0): products without a current store price are KEPT with empty price fields (`observations.json`
   57  `availability: no_store_price`); products without a UPC are KEPT with `upc` empty and Mariano's product id recorded as
   58  `source_product_id` (never in `upc`); products a run does not return are CARRIED from the last published dataset with
   59  their own last `crawl_date` (`status: carried`, `last_observed`, `carried_since`). The UPC only ever comes from
   60  `item.upc`; in all sampled real responses `item.upc` = product key = `data.id`, and a top-level `prod.id` does not exist.
   61  
   62  Excluded and counted in the report (`exclusions.json`, with the exact trigger): products whose own size or price wording
   63  is approximate / estimated (e.g. "about $10.39 each"); products from a different store (fails the run); products outside
   64  the shelf's sub-category; duplicates (first placement wins). A product is never excluded only because it is sold by
   65  weight, and titles (e.g. "(About 3 Steaks per Pack)", "Family Pack") never trigger an exclusion or a deal.
   66  
   67  ## Silent-blocking and completeness detection
   68  
   69  * response shape: missing application state, challenge page, response below `fetch.min_page_bytes` → retried, then failed
   70  * upstream failure: a search page that lists UPCs but carries no product details (Mariano's product service timed out) is
   71    **not** treated as an empty page – it is retried and fails the shelf if it persists
   72  * store context on every page and every price (`store_mismatches` must be 0)
   73  * canary search at start and end of the run
   74  * zero products on a shelf, category below minimum, yield drop vs the last published run → run not published
   75  * per-category report: shelves discovered / done / failed, pages read, products listed, products of the sub-category, kept
   76  
   77  ## Failed runs never replace good data
   78  
   79  `latest/` is written only by `storage.publish()`, which is called only when validation passed and the run was not a
   80  scoped demo. Files are staged first and the manifest is written last (commit point); the previous dataset is kept as
   81  `previous-records.json`. A run that fails keeps its own files under `runs/<run_id>/` for diagnosis only.
   82  
   83  ## Interruption recovery
   84  
   85  Each page's records and the listing's next-page pointer are written in one SQLite transaction. `run --resume`
   86  (and every scheduled run) continues the latest unfinished run: verified store, discovery results and committed pages are
   87  reused; failed shelves are retried; UPC is the primary key, so nothing is stored twice.
   88  
   89  
   90  ## Coverage proof (v1.1.0)
   91  
   92  Mariano's server-rendered search returns the first 24 results of a request whatever page number is asked for
   93  (verified: page 2 returns the same 24 UPCs with re-numbered ranks 25-48). Each seed request (shelf name / parts) that
   94  reports more products than it returned is partitioned with Mariano's own `brandName` filter; `coverage.json` reconciles
   95  every seed request's reported total against the distinct products read across the request and its brand slices
   96  (`gap` = remaining products, 0 = proven complete). Expansion requests add products and brands and are listed separately.
   97  
   98  ## Provenance (v1.1.0)
   99  
  100  `ledger.json`: one row per page used – time, kind, URL, SHA-256 + size of the exact response, store and request location
  101  ids and active modality read from it, products listed / priced, `sourceLocationId`s on its prices.
  102  `evidence/pages/<sha256>.json.gz`: the price-bearing excerpt of every page; `evidence/raw/`: full HTML for the first pages
  103  per category. `observations.json` links every output row to the SHA-256 of the response it was read from.
  104  `evidence/failed/` (v1.1.11): every response that arrived but could not be used (provider envelope not JSON or not the
  105  expected shape, page without application state, too small, HTTP error) keeps a sanitized copy bounded to
  106  `evidence.failed_response_max_bytes`, the SHA-256 of the exact original body, and a receipt (`<seq>-<attempt>-<sha>.json`,
  107  also appended to `receipts.jsonl` and the checkpoint `response_failed` event) with the URL, request body, attempt,
  108  budget ledger line, request / failure times and the error. Credentials, cookies and request headers are never stored.
  109  `report.json → provenance`: code SHA-256, config file SHA-256s, requirements SHA-256, Python, argv – recorded at run start,
  110  at every resume and at finish.

   84  def redact_text(text: str) -> str:
   85      """Remove credentials from free text: key=value / key: value pairs, Bearer and Basic values, user:password@ in
   86      URLs, and the literal values of the configured credential environment variables."""
   87      text = re.sub(r"(?i)\b(bearer|basic)\s+[A-Za-z0-9._~+/=-]{8,}", r"\1 [REDACTED]", text)
   88      text = re.sub(r"(?i)((?:proxy-)?authorization|password|passwd|secret|token|api[_-]?key|set-cookie|cookie)"
   89                    r"(\"?\s*[:=]\s*\"?)[^\s\",;}]+", r"\1\2[REDACTED]", text)
   90      text = re.sub(r"(?i)(https?://)[^/\s:@]+:[^/\s@]+@", r"\1[REDACTED]@", text)
   91      for name in _SECRET_ENV:
   92          value = os.getenv(name) or ""
   93          if len(value) >= 4:
   94              text = text.replace(value, "[REDACTED]")

  100      try:

  162  def save_failed_response(run_dir: Path, result, receipt: dict, max_bytes: int = 1_000_000) -> dict:
  163      """Archive a response that arrived but could not be used, even when it is not JSON or has an unsupported shape.
  164  
  165      `original_sha256` is the SHA-256 of the exact body received (the provider envelope when there is one, else the
  166      page). The stored copy is that body sanitized (credential keys, cookies, Bearer/Basic values, URL passwords and the
  167      configured credential values removed) and bounded to `max_bytes`, with its own `stored_sha256`. The receipt links
  168      both hashes to the request (URL, request body, attempt, budget ledger line), the timestamps and the failure.
  169      Request headers are never stored."""
  170      original = (result.raw_response or result.html or "").encode("utf-8")
  171      original_sha = sha256_bytes(original)
  172      envelope, request_id = sanitize_provider_response(original.decode("utf-8")) if original else ("", "")
  173      is_json = not isinstance(envelope, str)
  174      stored = (json.dumps(_redact_values(envelope), ensure_ascii=False) if is_json else envelope).encode("utf-8")
  175      truncated = len(stored) > max_bytes
  176      if truncated:
  177          stored = stored[:max_bytes].decode("utf-8", errors="ignore").encode("utf-8")
  178      directory = run_dir / "evidence" / "failed"
  179      directory.mkdir(parents=True, exist_ok=True)
  180      body_file = f"{original_sha}.{'json' if is_json else 'txt'}.gz"
  181      if not (directory / body_file).exists():
  182          (directory / body_file).write_bytes(gzip.compress(stored))
  183      request, _ = sanitize_provider_response(json.dumps(getattr(result, "request", None) or {}))
  184      record = {
  185          **_redact_values(receipt),
  186          "request_body": _redact_values(request),
  187          "provider_status": result.provider_status,
  188          "target_status": result.status or None,
  189          "request_id": request_id,
  190          "original_sha256": original_sha,
  191          "original_bytes": len(original),
  192          "original_format": "json" if is_json else "text",
  193          "stored_file": f"evidence/failed/{body_file}",
  194          "stored_sha256": sha256_bytes(stored),
  195          "stored_bytes": len(stored),
  196          "truncated": truncated,
  197          "sanitized": True,
  198      }
  199      name = f"{int(record.get('request_seq') or 0):04d}-{int(record.get('attempt') or 0)}-{original_sha[:16]}.json"
  200      record["receipt_file"] = f"evidence/failed/{name}"
  201      (directory / name).write_text(json.dumps(record, indent=2, ensure_ascii=False), encoding="utf-8")
  202      with (directory / "receipts.jsonl").open("a", encoding="utf-8") as f:
  203          f.write(json.dumps(record, ensure_ascii=False) + "\n")
  204      return record

  318  def realtime_payload(settings, location, url: str) -> dict:
  319      """Classic Web Scraper API body (realtime.oxylabs.io/v1/queries).
  320      Search pages (…/search?query=…): `fetch.oxylabs_realtime.search_payload` when configured – the documented
  321      `kroger_search` source with store localisation ({query}, {store_id}). Everything else: `…oxylabs_realtime.payload`."""
  322      from urllib.parse import parse_qs, urlparse
  323  
  324      u = urlparse(url)
  325      params = parse_qs(u.query, keep_blank_values=True)
  326      query = (params.get("query") or [""])[0]
  327      is_search = u.path.rstrip("/").endswith("/search") and bool(query)
  328      if is_search:
  329          allowed = {"query", "searchType", "brandName", "page", "savings"}
  330          unknown = set(params) - allowed
  331          unsupported = set(unknown)
  332          if int((params.get("page") or ["1"])[0] or 1) > 1:
  333              unsupported.add("page")
  334          if "savings" in params:
  335              unsupported.add("savings")
  336          if unsupported:
  337              names = "/".join(sorted(unsupported))
  338              raise FetchError(f"unsupported on Classic kroger_search: {names}", "compat")
  339      tpl = settings.get("fetch.oxylabs_realtime.search_payload") if is_search else None
  340      if not tpl:
  341          tpl = settings.get("fetch.oxylabs_realtime.payload") or {"source": "kroger", "url": "{url}", "store_id": "{store_id}"}
  342      modality = str(getattr(location, "expected_modality", "IN_STORE") or "IN_STORE").lower()
  343      body = _fill(tpl, url=url, query=query, store_id=location.store_id, zipcode=location.zipcode,
  344                   modality=modality, fulfillment_type=modality)
  345      # Keep the location pin and pickup mode authoritative even when a minimal
  346      # customer template omitted either field.
  347      if is_search:
  348          body.setdefault("store_id", location.store_id)
  349          body.setdefault("fulfillment_type", modality)
  350      brand = (params.get("brandName") or [""])[0]
  351      if is_search and brand:
  352          body["brand"] = brand
  353      return body

  313                  urls.append((f"{self.base}/search?query={quote(q)}&searchType=default_search", q))
  314              for url, q in urls:
  315                  self.ck.add_listing(cat.name, sh.name, url, q, tax, sh.curated)
  316              if self.s.get("coupons.product_flag_via_search_filter", True) and not sh.curated:
  317                  self.ck.add_listing(cat.name, sh.name, f"{self.base}/search?query={quote(sh.query)}&searchType=default_search"
  318                                      f"&savings=Coupons", f"{sh.query} | savings=Coupons", tax, False, mode="coupon_filter")
  319              kept += 1
  320          if not kept:
  321              self.ck.event("discovery_failed", {"category": cat.name, "url": cat.url})
  322              raise FetchError(f"no sub-categories found on {cat.url}", "malformed")
  323          self.ck.set(key, {"kind": "department", "shelves": kept, "skipped_brand_shelves": skipped, "department_code": dept,
  324                            "subcategories": [s.name for s in shelves if s.name not in skipped]})

  326      # ------------------------------------------------------------------ 3. crawl one listing
  327      async def crawl_pending(self) -> None:
  328          """Continuous work queue: every pending request starts as soon as the fetcher has a free slot, and requests
  329          queued by expansion / brand slices start as soon as they appear. (Up to 1.1.1 the crawl ran in waves: a wave
  330          waited for its slowest request, retries and back-off included, before the next wave started, leaving most
  331          parallel slots idle - the main reason for ~8-9 requests per minute on 21 Oct.) The fetcher's semaphore still
  332          bounds parallel requests (`fetch.concurrency`). Each request is started at most once per session; one left
  333          pending is picked up by the next resume."""
  334          running: dict[tuple, asyncio.Task] = {}
  335          started: set[tuple] = set()
  336          n = 0
  337          while True:
  338              for l in self.ck.pending():
  339                  key = (l["category"], l["url"])
  340                  if key not in started:
  341                      started.add(key)
  342                      running[key] = asyncio.create_task(self.crawl_listing(l))
  343              if not running:
  344                  break
  345              done, _ = await asyncio.wait(running.values(), return_when=asyncio.FIRST_COMPLETED)
  346              for key in [k for k, t in running.items() if t in done]:
  347                  exc = running.pop(key).exception()
  348                  if exc:
  349                      for t in running.values():
  350                          t.cancel()
  351                      raise exc
  352              n += len(done)
  353              if n % 50 < len(done):
  354                  log.info("crawl", extra={"requests_done": n, "requests_running": len(running),
  355                                           "requests_total": len(self.ck.listings()), "fetch": dict(self.fetcher.stats)})

  357      async def crawl_listing(self, l: dict) -> None:
  358          """Read one search request of a shelf.
  359  
  360          Mariano's server-rendered search returns the first 24 results of a request whatever page is asked for.
  361          Two mechanisms extend coverage: (1) brand slices – a request that reports more products than it returned is
  362          partitioned with Mariano's own `brandName` filter, one request per brand (slices are disjoint, and their
  363          reported totals reconcile against the parent request in coverage.json); (2) query expansion – new products
  364          queue queries built from their sub-commodity names and brands. Neither is capped by default."""
  365          cat, url, sub = l["category"], l["url"], l["sub_category"]
  366          page, streak = int(l["next_page"]), int(l["empty_streak"])
  367          paginate = bool(self.s.get("crawl.paginate", False))
  368          mode = l.get("mode") or "query"
  369          while True:
  370              if self.limit and self.ck.kept_in_category(cat) >= self.limit:
  371                  self.ck.finish_listing(cat, url, "demo_limit_reached")
  372                  return
  373              where = {"category": cat, "sub": sub, "query": l["query"]}
  374              try:
  375                  sp, _, sha = await self._search(_with_page(url, page), where, kind=f"search_{mode}")
  376              except FetchError as exc:
  377                  self.ck.fail_listing(cat, url, f"page {page}: {exc}")
  378                  self.ck.event("listing_failed", {"category": cat, "sub": sub, "query": l["query"], "error": str(exc)})
  379                  return
  380              if not self._store_ok(sp.store, f"{cat} / {sub} [{l['query']}]") or (
  381                      sp.request_location and sp.request_location != self.loc.store_id):
  382                  self.ck.fail_listing(cat, url, f"page {page}: store context mismatch")
  383                  return
  384              if mode == "brand_slice" and sp.upcs:
  385                  want = l["query"].split("| brand=", 1)[-1].strip().lower()
  386                  got = [((sp.products.get(u) or {}).get("data") or {}).get("item", {}).get("brand", {}).get("name", "").lower()
  387                         for u in sp.upcs]
  388                  share = sum(1 for b in got if b == want) / len(got)
  389                  if share < float(self.s.get("crawl.brand_slice_min_share", 0.9)):
  390                      # Mariano's ignored the brand filter: never count this response as coverage of the slice
  391                      self.ck.fail_listing(cat, url, f"brand filter not honored ({share:.0%} of products are '{want}')")
  392                      self.ck.event("brand_filter_not_honored", {"query": l["query"], "share": share})
  393                      return
  394              accepted, skipped, matched, terms, obs, excl, listed = [], [], 0, [], [], [], []
  395              coupon_rows: list[tuple[str, str, str]] = []
  396              ctx = self._ctx(cat, sub)
  397              for upc in sp.upcs:
  398                  prod = sp.products.get(upc)
  399                  item = ((prod or {}).get("data") or {}).get("item") or {}
  400                  listed.append((upc, (item.get("brand") or {}).get("name", "")))
  401                  if not parse.matches(parse.product_codes(prod, sp.codes.get(upc)), l["taxonomy"]):
  402                      skipped.append((upc, "outside_subcategory"))
  403                      continue
  404                  matched += 1
  405                  if not prod or "data" not in prod:
  406                      skipped.append((upc, "no_product_data"))
  407                      continue
  408                  m = parse.map_product(prod, ctx)
  409                  if m.reason == "store_mismatch":
  410                      self.ck.incr("store_mismatches")
  411                      self.ck.event("store_mismatch", {"upc": upc, "source": m.source_location})
  412                  for text, tpl in m.offer_labels:
  413                      e = self.census.setdefault(text, {"count": 0, "template": tpl})
  414                      e["count"] += 1
  415                  if m.record:
  416                      accepted.append((m.identity, sub, m.record))
  417                      obs.append({"identity": m.identity, "upc": m.record["upc"], "source_product_id": m.source_product_id,
  418                                  "identity_source": m.identity_source, "availability": m.availability,
  419                                  "sell_by": m.sell_by, "modalities": json.dumps(m.modalities),
  420                                  "offers": json.dumps(m.offers, ensure_ascii=False), "response_sha256": sha,
  421                                  "observed_at": _now(), "query": l["query"]})
  422                  else:
  423                      skipped.append((m.identity or upc, m.reason))
  424                      if m.reason == "approximate_weight":
  425                          excl.append({"identity": m.identity, "category": cat, "sub_category": sub, "reason": m.reason,
  426                                       "trigger_field": m.trigger[0], "trigger_text": m.trigger[1], "response_sha256": sha})
  427                  if mode in ("query", "expansion"):
  428                      terms.extend(parse.expansion_terms(prod, l["taxonomy"], sub))
  429                  if mode == "coupon_filter" and m.identity:
  430                      coupon_rows.append((m.identity, l["query"], sha))
  431              streak = 0 if matched else streak + 1
  432              done, reason = True, "single_page_request"
  433              if paginate:
  434                  done, reason = False, ""
  435                  if len(sp.upcs) < self.page_size or (sp.total and page * self.page_size >= sp.total):
  436                      done, reason = True, "end_of_results"
  437                  elif streak >= self.empty_stop:
  438                      done, reason = True, f"no_matching_products_in_{self.empty_stop}_pages"
  439                  elif page >= self.max_pages:
  440                      done, reason = True, "query_page_window_reached"
  441              self.ck.listing_items_add(url, listed)
  442              self.ck.observe(obs)
  443              self.ck.exclude(excl)
  444              self.ck.flag_coupons(coupon_rows)
  445              new = self.ck.commit_page(cat, url, page, accepted, skipped, len(sp.upcs), matched, done, reason, streak, sp.total)
  446              sliced = self._slice(l, sp, listed) if mode == "query" else 0
  447              queued = self._expand(l, terms) if (new and mode in ("query", "expansion")) else 0
  448              log.info("request", extra={"category": cat, "sub": sub, "query": l["query"], "mode": mode,
  449                                         "listed": len(sp.upcs), "matched": matched, "new_records": new,
  450                                         "reported_total": sp.total, "brand_slices_queued": sliced,
  451                                         "queries_queued": queued, "response_sha256": sha})
  452              if done:
  453                  return
  454              page += 1
  455  
  456      def _slice(self, l: dict, sp: parse.SearchPage, listed: list[tuple[str, str]]) -> int:
  457          """Partition a SEED request (the shelf's own name / parts) that reports more than it returned into brand slices
  458          (Mariano's brandName filter). Expansion requests are discovery helpers and are not partitioned."""
  459          if not self.s.get("crawl.brand_slices", True) or sp.total <= len(sp.upcs):
  460              return 0
  461          brands = {b for _, b in listed if b}
  462          # brands seen anywhere in this shelf can also hide in this request's unseen remainder
  463          for (b,) in self.ck.db.execute(
  464                  "SELECT DISTINCT li.brand FROM listing_items li JOIN listings l ON l.url = li.url "
  465                  "WHERE l.category=? AND l.sub_category=? AND li.brand != ''", (l["category"], l["sub_category"])):
  466              brands.add(b)
  467          cap = int(self.s.get("crawl.max_brand_slices_per_request", 0))
  468          added = 0
  469          for b in sorted(brands):
  470              if cap and added >= cap:
  471                  break
  472              sep = "&" if "?" in l["url"] else "?"
  473              if self.ck.add_listing(l["category"], l["sub_category"], f"{l['url']}{sep}brandName={quote(b)}",
  474                                     f"{l['query']} | brand={b}", l["taxonomy"], bool(l["curated"]),
  475                                     mode="brand_slice", parent=l["url"]):
  476                  added += 1
  477          return added
  478  
  479      def _expand(self, l: dict, terms: list[str]) -> int:
  480          cap = int(self.s.get("crawl.max_queries_per_shelf", 0))
  481          shelf = [x for x in self.ck.listings() if x["category"] == l["category"] and x["sub_category"] == l["sub_category"]
  482                   and (x.get("mode") or "query") in ("query", "expansion")]
  483          used = {x["query"].lower() for x in shelf}
  484          added = 0
  485          for t in terms:
  486              if cap and len(shelf) + added >= cap:
  487                  break
  488              if t.lower() in used:
  489                  continue
  490              used.add(t.lower())
  491              self.ck.add_listing(l["category"], l["sub_category"],
  492                                  f"{self.base}/search?query={quote(t)}&searchType=default_search",
  493                                  t, l["taxonomy"], bool(l["curated"]), mode="expansion")
  494              added += 1
  495          return added

  515      # ------------------------------------------------------------------ main
  516      async def run(self, publish: bool = True) -> dict:
  517          t0 = time.monotonic()
  518          started = self.ck.get("started_at")
  519          if not started:
  520              self.ck.set("started_at", _now())
  521              self.ck.set("crawl_date", datetime.now(timezone.utc).date().isoformat())
  522              self.ck.set("scope", {"categories": [c.name for c in self.cats], "limit_per_category": self.limit,
  523                                    "scoped_demo": self.scoped or bool(self.limit)})
  524              self.ck.set("provenance_start", {**evidence.fingerprints(self.s), "recorded_at": _now()})
  525          else:
  526              self.ck.incr("resumes")
  527              fp = {**evidence.fingerprints(self.s), "recorded_at": _now()}
  528              hist = self.ck.get("provenance_resumes", [])
  529              hist.append(fp)
  530              self.ck.set("provenance_resumes", hist)
  531              self.ck.event("resumed", {"retried_failed_listings": self.ck.retry_failed(),
  532                                        "items_already_kept": self.ck.db.execute("SELECT COUNT(*) FROM items").fetchone()[0],
  533                                        "pending_requests": len(self.ck.pending()), "code_sha256": fp["code_sha256"]})
  534          await self.fetcher.start()
  535          try:
  536              store = self.ck.get("store_verification") or {}
  537              if not store.get("verified"):
  538                  store = await self.verify_store()
  539                  if not store["verified"]:
  540                      raise RuntimeError(f"store verification failed: {store['checks']}")
  541              if not (self.ck.get("canary") or {}).get("start"):
  542                  await self.canary("start")
  543              for cat in self.cats:
  544                  try:
  545                      await self.discover(cat)
  546                      if self.ck.get(f"discovery_error:{cat.name}"):
  547                          self.ck.set(f"discovery_error:{cat.name}", None)   # earlier failure healed on resume
  548                  except FetchError as exc:
  549                      self.ck.set(f"discovery_error:{cat.name}", str(exc))
  550                      log.error("discovery failed", extra={"category": cat.name, "error": str(exc)})
  551              await self.crawl_pending()
  552              self.ck.set("offer_census", self.census)
  553              for cat in self.cats:
  554                  if cat.kind == "coupons" and self.s.get("coupons.enabled", True):
  555                      try:
  556                          await self.collect_coupons(cat)
  557                      except FetchError as exc:
  558                          self.ck.set("coupons_error", str(exc))
  559              await self.canary("end")
  560          finally:
  561              self.ck.set("offer_census", self.census)
  562              prev = self.ck.get("fetch_stats_before_resume", [])
  563              self.ck.set("fetch_stats", {**self.fetcher.stats, "provider": self.fetcher.name, "earlier_sessions": prev})
  564              prev.append({**self.fetcher.stats, "ended_at": _now()})
  565              self.ck.set("fetch_stats_before_resume", prev)
  566              await self.fetcher.close()
  567              self.ck.flush(force=True)
  568          runtime = time.monotonic() - t0 + float(self.ck.get("runtime_before_resume", 0))
  569          self.ck.set("runtime_before_resume", runtime)
  570          return self.finish(runtime, publish)

  573      def _previous(self) -> tuple[dict, dict]:
  574          prev_recs = self.storage.get_json(f"{self.loc.key}/latest/records.json") or []
  575          prev_obs = self.storage.get_json(f"{self.loc.key}/latest/observations.json") or {}
  576          by_url = {o.get("url"): k for k, o in prev_obs.items() if o.get("url")}
  577          out = {}
  578          for r in prev_recs:
  579              ident = r.get("upc") or by_url.get(r.get("url"), "")
  580              if ident:
  581                  out[ident] = r
  582          return out, prev_obs

  584      def finish(self, runtime: float, publish: bool) -> dict:
  585          fresh = self.ck.identified_records()
  586          fresh_obs = {}
  587          for o in self.ck.table("observations"):
  588              o = dict(o)
  589              o["modalities"] = json.loads(o["modalities"] or "{}")
  590              o["offers"] = json.loads(o["offers"] or "[]")
  591              if o["identity"] in fresh:
  592                  o["url"] = fresh[o["identity"]].get("url", "")
  593              fresh_obs[o["identity"]] = o
  594          for row in self.ck.table("coupon_flags"):
  595              o = fresh_obs.get(row["identity"])
  596              if o is not None:   # Mariano's savings=Coupons filter lists this product (coupon terms not exposed)
  597                  o.setdefault("digital_coupon_available", {"source": "marianos.com search filter savings=Coupons",
  598                                                            "evidence_response_sha256": row["response_sha256"],
  599                                                            "query": row["query"]})
  600          demo = (self.ck.get("scope") or {}).get("scoped_demo")
  601          prev_recs, prev_obs = ({}, {}) if demo else self._previous()   # demo scope never carries / publishes
  602          recs_by_id, obs = retention.carry_forward(fresh, fresh_obs, prev_recs, prev_obs, self.run_id, self.ck.get("crawl_date"))
  603          records = list(recs_by_id.values())
  604          prev_report = self.storage.get_json(f"{self.loc.key}/latest/report.json")
  605          v = validate_run(self.s, self.ck, records, self.cats, prev_report, obs, recs_by_id)
  606          cov = coverage.reconcile(self.ck.listings(), self.ck.table("listing_items"), self.ck.table("ledger"))
  607          if cov["summary"]["unexplained_gap"]:
  608              v.fail(f"coverage: {cov['summary']['unexplained_gap']} product(s) in gaps without an explained reason")
  609          if cov["summary"]["queries"] and cov["summary"]["queries_complete"] < cov["summary"]["queries"]:
  610              v.warn(f"coverage: {cov['summary']['queries'] - cov['summary']['queries_complete']} of "
  611                     f"{cov['summary']['queries']} seed requests not proven complete (explained in coverage.json)")
  612          if demo:
  613              v.warn("demo scope (category subset / per-category limit): never published to latest/")
  614          provenance = {"start": self.ck.get("provenance_start"), "resumes": self.ck.get("provenance_resumes", []),
  615                        "finish": {**evidence.fingerprints(self.s), "recorded_at": _now()}}
  616          report = build_report(self.run_id, self.loc, self.ck, records, runtime, v.as_dict(), self.s, self.cats,
  617                                obs=obs, coverage=cov, provenance=provenance)
  618          files = {
  619              "records.json": json.dumps(records, ensure_ascii=False, indent=2),
  620              "report.json": json.dumps(report, ensure_ascii=False, indent=2),
  621              "observations.json": json.dumps(obs, ensure_ascii=False, indent=2),
  622              "coverage.json": json.dumps(cov, ensure_ascii=False, indent=2),
  623              "exclusions.json": json.dumps(self.ck.table("exclusions"), ensure_ascii=False, indent=2),
  624              "ledger.json": json.dumps(self.ck.table("ledger"), ensure_ascii=False, indent=2),
  625          }
  626          cp = self.dir / "coupons.json"
  627          if cp.exists():
  628              files["coupons.json"] = cp.read_text(encoding="utf-8")
  629          base = f"{self.loc.key}/runs/{self.run_id}"
  630          for name, body in files.items():
  631              (self.dir / name).write_text(body, encoding="utf-8")
  632              self.storage.put_bytes(f"{base}/{name}", body.encode("utf-8"))
  633          status = "validation_failed"
  634          self.ck.flush(force=True)       # durable checkpoint before anything is published
  635          if v.ok and not demo and publish:
  636              extras = {k: files[k] for k in ("observations.json", "coverage.json") if k in files}
  637              self.storage.publish(self.loc.key, self.run_id, records, report, extras=extras)
  638              status = "published"
  639          elif v.ok:
  640              status = "valid_not_published_demo" if demo else "valid_not_published"
  641          self.ck.set("final_status", status)
  642          self.ck.event("final_status", {"status": status, "records": len(records), "errors": v.errors[:20]})
  643          self.ck.flush(force=True)
  644          log.info("run finished", extra={"status": status, "records": len(records), "errors": v.errors[:10]})
  645          return {"run_id": self.run_id, "status": status, "records": len(records), "dir": str(self.dir),
  646                  "errors": v.errors, "warnings": v.warnings}

    5  SHA-256 of the exact original, in a failure receipt linked to the request, the budget ledger line and the timestamps.
    6  Offline only: provider HTTP is mocked with httpx.MockTransport; no request leaves the machine.

   30  @pytest.fixture(autouse=True)
   31  def _offline(monkeypatch):
   32      monkeypatch.setattr("mscraper.fetch.Fetcher._pace", lambda self: asyncio.sleep(0))
   33      monkeypatch.setattr("mscraper.fetch.random.uniform", lambda a, b: 0)
   34      for k, v in SECRETS.items():
   35          monkeypatch.setenv(k, v)

   38  def _mock(monkeypatch, responses):
   39      """httpx.AsyncClient answers each provider POST with the next (status, body); every request body is recorded."""
   40      sent, queue = [], list(responses)
   41  
   42      def handler(request):
   43          sent.append(json.loads(request.content))
   44          status, body = queue.pop(0)
   45          return httpx.Response(status, content=body.encode("utf-8") if isinstance(body, str) else body)
   46      real = httpx.AsyncClient
   47      monkeypatch.setattr(httpx, "AsyncClient", lambda *a, **kw: real(*a, **{**kw, "transport": httpx.MockTransport(handler)}))
   48      return sent

   51  def _receipts(run_dir):
   52      d = run_dir / "evidence" / "failed"
   53      return [json.loads(x) for x in (d / "receipts.jsonl").read_text(encoding="utf-8").splitlines()] if d.exists() else []
   54  
   55  
   56  def _stored(run_dir, rec):
   57      return gzip.decompress((run_dir / rec["stored_file"]).read_bytes())
   58  
   59  
   60  def _no_secret(run_dir):
   61      blob = b"".join(gzip.decompress(f.read_bytes()) if f.suffix == ".gz" else f.read_bytes()
   62                      for f in (run_dir / "evidence" / "failed").iterdir())
   63      for v in SECRETS.values():
   64          assert v.encode() not in blob
   65      assert b"dXNlcjpwYXNzd29yZA==" not in blob and b"tok-77aa" not in blob
   66

   68  def _runner(tmp_path, provider=OxylabsRealtimeFetcher, max_bytes=None):
   69      settings = load_settings(CFG)
   70      settings.raw["fetch"]["min_page_bytes"] = 1000
   71      if max_bytes:
   72          settings.raw["evidence"]["failed_response_max_bytes"] = max_bytes
   73      loc = settings.location(VERNON)
   74      f = provider(settings, loc)
   75      f.client = httpx.AsyncClient()
   76      f.backoff = 0
   77      return Runner(settings, loc, LocalStorage(tmp_path / "output"), tmp_path / "state", fetcher=f)
   78  
   79  
   80  def _verify(runner, retries=0):
   81      runner.fetcher.retries = retries
   82      with pytest.raises(FetchError) as exc:
   83          asyncio.run(runner.verify_store())
   84      return exc.value

   87  # ---------------------------------------------------------------- the reviewer's case, through the real CLI
   88  def test_cli_verify_store_malformed_http200_body_is_preserved_with_receipt(tmp_path, monkeypatch):
   89      monkeypatch.setenv("MSCRAPER_STATE_DIR", str(tmp_path / "state"))
   90      monkeypatch.setenv("MSCRAPER_FETCH_PROVIDER", "oxylabs_realtime")
   91      sent = _mock(monkeypatch, [(200, NOT_JSON)])
   92      with pytest.raises(FetchError) as exc:
   93          cli.main(["--config", CFG, "--budget", "qual:1", "verify-store", "--location", VERNON, "--max-requests", "1"])
   94      assert exc.value.kind == "malformed" and len(sent) == 1           # one attempt, exactly as before
   95      assert sent[0]["store_id"] == "53100502" and sent[0]["fulfillment_type"] == "pickup"
   96      runs = list((tmp_path / "state" / "_verify" / VERNON / "runs").iterdir())
   97      assert len(runs) == 1
   98      [rec] = _receipts(runs[0])
   99      ledger = [json.loads(x) for x in (tmp_path / "state" / "_budgets" / "qual.jsonl").read_text("utf-8").splitlines()]
  100      assert len(ledger) == 1 and rec["budget"] == "qual" and rec["budget_request_n"] == ledger[0]["n"] == 1
  101      assert rec["url"] == ledger[0]["url"] and rec["attempt"] == 1 and rec["request_seq"] == 1
  102      assert rec["requested_at"] and rec["failed_at"] >= rec["requested_at"]
  103      assert rec["error_kind"] == "malformed" and "could not be parsed" in rec["error"]
  104      assert rec["provider_status"] == 200 and rec["original_format"] == "text"
  105      assert rec["original_sha256"] == hashlib.sha256(NOT_JSON.encode()).hexdigest()
  106      assert rec["original_bytes"] == len(NOT_JSON.encode()) and not rec["truncated"]
  107      assert rec["request_body"]["source"] == "kroger_search" and rec["request_body"]["store_id"] == "53100502"
  108      body = _stored(runs[0], rec)
  109      assert b"Upstream gateway error" in body and hashlib.sha256(body).hexdigest() == rec["stored_sha256"]
  110      assert json.loads((runs[0] / rec["receipt_file"]).read_text("utf-8")) == rec
  111      _no_secret(runs[0])

  114  # ---------------------------------------------------------------- malformed / non-JSON / unsupported shapes
  115  @pytest.mark.parametrize("body,fmt", [
  116      (NOT_JSON, "text"),                                              # not JSON at all
  117      ("", "text"),                                                    # empty HTTP-200 body
  118      ('{"results": [{"content": "<html>', "text"),                    # truncated JSON
  119      ("[1, 2, 3]", "json"),                                           # JSON, but a list
  120      ('{"results": "not-a-list"}', "json"),                           # results of the wrong type
  121      ('{"results": [{"content": "<html></html>", "status_code": "n/a"}]}', "json"),   # non-numeric target status
  122  ], ids=["not-json", "empty", "truncated-json", "json-list", "results-wrong-type", "non-numeric-status"])
  123  def test_unsupported_provider_shapes_are_archived_not_discarded(tmp_path, monkeypatch, body, fmt):
  124      _mock(monkeypatch, [(200, body)])
  125      runner = _runner(tmp_path)
  126      assert _verify(runner).kind == "malformed"
  127      [rec] = _receipts(runner.dir)
  128      assert rec["original_sha256"] == hashlib.sha256(body.encode()).hexdigest() and rec["original_format"] == fmt
  129      assert (runner.dir / rec["stored_file"]).exists()
  130      events = [json.loads(d) for k, d in runner.ck.db.execute("SELECT kind, detail FROM events") if k == "response_failed"]
  131      assert [e["original_sha256"] for e in events] == [rec["original_sha256"]]
  132      assert events[0]["receipt_file"] == rec["receipt_file"]
