- Every test mocks the provider's HTTP response (`httpx.MockTransport`). No request left the machine. This proves the evidence path only. It does not show what a live provider returns.
- Account support for `kroger_search` and the proposed route, and genuine Vernon Hills Pickup store-qualified data, are still unverified. They remain qualification questions, not working routes.
- If the provider's own job ID or receipt is in a malformed body, it is kept in the stored copy. `request_id` is filled in only when the body is JSON.
