Working Python scraper, not a template. Reads Walmart's embedded page JSON, verifies the store on the store page and on every listing/product page, and keeps only local pickup/in-store Walmart.com offers. Marketplace, shipping-only, sponsored and approx-weight items are excluded; item-ID dedup. Exact 22-field JSON, empty strings, PPM copied as displayed, gupc/unit_price empty, volume vs digital deals split without calculating prices. Silent-block detection: challenge + shape checks, zero items = failure, canary items, yield vs last good run. SQLite checkpoints give true resume; latest/ is replaced only after validation passes. Azure: Container Apps Job (Mon+Thu), Blob, Key Vault, managed identity, Log Analytics, one-command Bicep deploy. 21 automated tests incl. hard-kill resume, thin-listing and failed-run protection.
