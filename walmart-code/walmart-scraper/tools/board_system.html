FLOW Every run, every location

01LockBlob lease per location → scheduled runs can never overlap
02Verify storeStore page: id, name, address and ZIP must match config before collecting
03Canary · startKnown items must show a local Walmart offer at this store
04DiscoverCategory → all subcategories from CSV, exclusions applied (Recipes, Farm Animals…)
05PaginatePickup facet · shape check · store check · filter · dedup · checkpoint per page
06EnrichProduct page: UPC, size, seller and store re-checked, deals
07Canary · endSame items re-read; detects blocking that starts mid-run
08Validate → publishAll checks pass → latest/ swapped atomically. Otherwise last good data stays.

BLOCK Silent-blocking detection

  • Challenge pages, block redirects, HTTP errors, tiny or slow responses
  • Response-shape validation: a changed page raises an error, never “0 items”
  • Zero-item listing = failure, not an empty category
  • Yield vs last good run (< 60 % blocks publish)
  • Canary products at start and end

SAFE Good data is never replaced

  • Runs write to runs/<id>/ only
  • latest/ swapped only after validation passes
  • Store mismatch on any page blocks the run
  • SQLite checkpoint: page + records in one transaction → true resume
  • Blob versioning + previous-records rollback
